# 🖼️ COCO Dataset Exploration and Analysis

## 📌 Project Overview

This project explores and analyzes the COCO (Common Objects in Context) 2017 Validation Dataset to understand its structure and characteristics for computer vision and text-to-image applications.

---

## 📂 Dataset Used

**Dataset:** COCO 2017 Validation Dataset

* Total Images: 5,000
* Total Classes: 80
* Total Captions: 25,000
* Captions per Image: 5

---

## 🎯 Objectives

* Load and examine a public dataset
* Analyze the number of object classes
* Study caption lengths
* Analyze image resolutions
* Display images with their text descriptions

---

## 🔍 Analysis Performed

* Loaded COCO annotations and validation images
* Explored all 80 object categories
* Calculated caption statistics (average, minimum, and maximum lengths)
* Analyzed image resolutions (width and height)
* Visualized caption length distribution using a histogram
* Visualized image resolution distribution using a scatter plot
* Displayed sample images along with their captions
